# Public Web Data Collection & Research

A collection of practical projects focused on collecting publicly
available information from the web, cleaning and validating datasets,
and organizing results into structured CSV and Excel files.

## Core Capabilities

- Public web research
- Data extraction and collection
- Multi-page and paginated data collection
- Data cleaning and transformation
- Data validation
- Duplicate and missing-value checks
- Basic data analysis
- Source identification
- CSV and Excel organization
- Python-based automation

## Projects

### 01 — Web Data Collection
**Focus:** Collection

Collected and organized publicly available information from multiple
web pages into a structured CSV dataset, using automated pagination
and basic HTTP error handling.

**Result:** 100 records

[View project →](./project001/)

---

### 02 — Book Data Analysis
**Focus:** Processing & Analysis

Collected 1,000 publicly available book records, cleaned and
transformed price data, and generated basic price statistics
and ranked lists.

**Result:** 1,000 records

[View project →](./project002/)

---

### 03 — Job Listing Validation
**Focus:** Validation & Filtering

Collected public job listings, cleaned and transformed the data,
checked for duplicates and missing values, and generated a filtered
dataset based on publication date.

**Result:** 30 listings · 0 duplicates · 0 missing values

[View project →](./project003/)

---

### 04 — Job Data Organization
**Focus:** Client-style Delivery

Simulated a client request for public job data by collecting and
validating records, identifying source URLs, and delivering
structured datasets in CSV and Excel.

**Result:** 30 listings · 10 companies · 0 duplicates ·
0 missing values · 0 empty values

[View project →](./project004/)
